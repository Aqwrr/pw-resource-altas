# PW Resource Atlas

Ресурсный атлас для обычного клиента **Comeback PW 1.3.6**: материалы и травы, фильтры, свои пресеты, маршруты сбора, карта и миникарта в игре, маяки выбранных ресурсов.

[Скачать последнюю версию](https://github.com/Aqwrr/pw-resource-altas/releases/latest/download/PW-Resource-Atlas-update.zip) · [Все релизы и изменения](https://github.com/Aqwrr/pw-resource-altas/releases)

## Установка

1. Распакуйте архив в отдельную папку. Оставьте `_internal` рядом с `PW-Resource-Atlas.exe`.
2. Запустите EXE и укажите папку клиента 1.3.6 в мастере первого запуска. Путь изначально пустой; русские буквы и пробелы поддерживаются.
3. Выберите ресурсы и примените мод при закрытой игре.

Если у вас атлас 2.7 или более ранний, один раз распакуйте новый архив поверх папки утилиты при закрытом атласе. В архиве нет личных настроек, пресетов и резервных копий.

## Обновления

Кнопка **«Обновления»** — внизу окна; также доступна через меню «Справка».

- Проверка стабильной версии включена при запуске и раз в 4 часа.
- Новую версию можно скачать и установить с перезапуском вручную.
- Опция **«Автообновление при закрытии атласа»** загружает обновление в фоне и применяет его после закрытия атласа.
- Учётная запись GitHub пользователям не требуется.

Обновление сохраняет фильтры, путь клиента, пресеты, журналы установки и резервные копии. Программа проверяет SHA-256 архива и файлов, делает копию прежней утилиты и проверяет запуск новой. При ошибке замены или проверки запуска выполняется откат.

Игра при обновлении утилиты не закрывается, её файлы не меняются. Если в релизе изменён сам мод, примените выбранный набор обычной кнопкой установки после выхода из игры.

Поддерживается обычный клиент Comeback 1.3.6. Версия 1.4.6 и тестовые EXE требуют отдельной адаптации.

## Карта и фильтры

При открытии показаны все уровни и весь каталог ресурсов. Быстрый набор меняет галочки; остальные строки остаются доступными. **«Показать все»** убирает ограничения поиска и категорий, сохраняя галочки. **«Сбросить выбор»** снимает галочки и возвращает «Все уровни» / «Всё». Сохранить и изменить свой набор можно через **«Мои наборы…»**.

**«Карта поверх игры»** открывает отдельное окно только с картой. Перемещайте его за заголовок и растягивайте за края под размер окна игры. Масштаб независим от основного окна, ресурсы и маршрут общие; положение и размер сохраняются.

## Выпуск новой версии

Этот репозиторий хранит релизы и инструменты публикации. Пакет собирается из проверенной Windows-сборки атласа; личная рабочая папка и оригиналы клиента не публикуются.

```powershell
python release-tools/build_release.py --bundle "C:\путь\к\сборке" --output "C:\путь\к\релизу" --notes "changes.md"
python release-tools/publish_release.py --package-dir "C:\путь\к\релизу" --publish
```

Для публикации нужна локальная авторизация владельца в GitHub через Git. Без `--publish` создаётся черновик. Токены не включаются в приложение и пакеты.

Обязательные файлы релиза: `PW-Resource-Atlas-update.zip`, `atlas-release.json`, `SHA256SUMS.txt`. Тег совпадает с версией пакета, например `v2.9`. Черновики и предварительные релизы не устанавливаются автоматически.
