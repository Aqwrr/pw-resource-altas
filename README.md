# PW Resource Atlas

Материалы и травы для Comeback PW 1.3.6: карта, миникарта, маршруты, свои наборы и маяки.

[Скачать](https://github.com/Aqwrr/pw-resource-altas/releases/latest/download/PW-Resource-Atlas-update.zip) · [Изменения](https://github.com/Aqwrr/pw-resource-altas/releases)

## Установка

1. Распакуйте архив. Оставьте `_internal` рядом с EXE.
2. Запустите атлас и укажите папку игры. Русские буквы и пробелы поддерживаются.
3. Выберите ресурсы, закройте игру и установите набор.

Короткие инструкции доступны в меню **«Справка»** внутри программы. Клиенты 1.4.6 и тестовые EXE пока не поддерживаются.

## Обновления

Откройте **«Справка → Обновления»**. Проверка включена при запуске и раз в 4 часа. Автообновление при выходе можно включить отдельно.

Обновление сохраняет настройки, пресеты, журналы установки и резервные копии. При ошибке запуска выполняется откат. Игровой мод устанавливается отдельно. Для перехода с 2.7 и старше один раз распакуйте свежий архив поверх папки атласа при закрытой программе.

## Разработка

Python 3.12, Windows. Команды выполняются из корня репозитория:

```powershell
make deps
make test
make run
```

Если Make не установлен: `python tools/project.py test` и аналогично для других команд.

| Команда | Действие |
| --- | --- |
| `make assets` | Скачать проверенные ресурсы для сборки |
| `make lint` / `make format` | Проверить / выровнять стиль кода |
| `make test` | Проверить карту, установку, обновления и интерфейс |
| `make build` | Собрать EXE и проверить его запуск |
| `make package` | Создать OTA-архив из готовой сборки |
| `make release` | Проверки, сборка и OTA-архив одной командой |
| `make publish` | Опубликовать готовый релиз через локальную авторизацию Git |
| `make clean` | Удалить только каталог `build/` |

Исходники — `src/`, проверки — `tests/`, команды — `tools/`, изменения версий — `release-notes/`. Результаты сборки — `build/`. Настройки запуска из исходников хранятся отдельно в `.local/`.

Ресурсы загружаются из закреплённого публичного релиза с проверкой SHA-256. Своя папка ресурсов: переменная `ATLAS_ASSETS_DIR`. Игра для сборки и проверок не требуется.

## Выпуск версии

1. Измените `VERSION` в `src/atlas_core.py` и добавьте `release-notes/<версия>.md`.
2. Выполните `make release` для локальной проверки.
3. Отправьте коммит и тег `v<версия>` на GitHub.

GitHub Actions проверяет тег, запускает проверки, собирает Windows-приложение и публикует обновление. Коммиты и pull request проверяются отдельно. Запуск workflow вручную только проверяет и собирает; публикация выполняется по тегу.

Токен GitHub Actions выдаётся на время задания. В программу, архив и исходники токены не попадают. Пользователям GitHub-аккаунт не нужен.
